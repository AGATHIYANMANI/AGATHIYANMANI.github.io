04 / Selected work

Projects that show how I think

Each project is presented as a problem-solving story rather than a simple technology list.

01

BosBot — Biodegradable Ingestible Capsule

A swallowable, biodegradable capsule-robot concept for gastrointestinal monitoring. The concept explores sensors and a micro-camera, wireless power transfer from an external wearable transmitter, biodegradable materials and post-use degradation, with the goal of collecting diagnostic information without a conventional internal battery.

IoT ConceptSensorsMicro CameraWireless PowerBiodegradable Design
02

Biotech AI Assistant

An AI tutor-style assistant concept for biotechnology learning. The project explores a backend using Node.js and Express, environment configuration and AI API integration to create a learning-focused assistant that can explain biotechnology concepts.

AI AssistantAPI Integration
03

Geospatial Flood / Sea-Level Analysis

A geospatial analysis project exploring DEM elevation, potential inundation, flood depth and coastline-related outputs. The work focuses on geographic processing and understanding how elevation and spatial relationships affect flood-analysis results.

MATLABDEMGeospatialSpatial Analysis

Java Database & Web Applications

Hands-on development and learning across Java programming, SQL, MySQL, JDBC and Java Servlets. This includes database connectivity, CRUD-style operations, backend request handling, algorithmic problem solving and debugging practical development issues.
